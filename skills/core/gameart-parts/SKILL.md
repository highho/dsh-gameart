# 角色部件分层：验收与接入

## 产线做什么

一张 640×896 的角色图（`upper body` 或 `portrait`），拆成**两张互斥**的 RGBA：

- `part_head_*.png` —— 头部（含头发、发饰）
- `part_body_*.png` —— 身体（含脖子、肩、胸、手臂）

两张**像素级不重叠**。这层互斥是整条链的核心价值：动画里转头、点头时头部图层独立位移，
下面不能露出一块「被挖掉的身体」或者「重影的头」。

## 链路（照着理解，不要随手改参数）

```
InvertMask(source alpha)  ∪  RMBG-2.0 out1        ← 两路前景合并，补上 RMBG 漏掉的
        ↓
face bbox（阈值 0.30 / 膨胀 12）                  ← 给 SAM 一个「头在这儿」的提示框
        ↓
SAMDetectorCombined（阈值 0.88, hint=center-1）    ← 框内精确分割出头
        ↓
GrowMask expand 25                                ← 把下巴/脖颈交界稍微放一点
        ↓
head = 上面这个；body = foreground − head
        ↓
两层分别与 foreground 求交（防溢出）
        ↓
InvertMask → JoinImageWithAlpha                   ← 变回 RGBA
```

实测数据（`samples/10/`）：head 占 1.91%、body 占 51.85%、并集 53.76%，
**重叠 0 px**，透明区 RGB 最大值 0。

## 为什么 `GrowMask expand` 是 25，不是 70

expand 决定「头」这张蒙版往外扩多少像素。

- 太小（<10）：下巴和脖子交界处会留一条缝，动画一点头就看见背景。
- 25：刚好盖住下巴轮廓，脖子还是归身体。
- 70：把脖子、斜方肌、甚至一部分肩都吃进「头」层。转头的时候整个肩膀跟着转，
  看起来像脖子断了一半。

**这是量出来的数，不是拍的。** 用户说「头多一点」时，先问清楚是要多到哪，
别直接把 25 改成 70。

## 为什么要 `InvertMask → JoinImageWithAlpha`

ComfyUI 里 `VAEDecode` 出来是 RGB，蒙版是独立的单通道。`JoinImageWithAlpha`
把「图 + 蒙版」合成 RGBA——**注意它是用 alpha 反着取的**，所以要先把蒙版
`InvertMask` 一次。这一步写反了的症状是：角色没了，背景全留着。看到这个就知道是哪错了。

## 为什么要清零透明区 RGB

PNG 的透明像素仍然存 RGB 值。引擎做双线性过滤时，会用透明像素的 RGB 去插值边缘，
如果那些 RGB 是黑的，角色周围就出现一圈**黑边**（暗色描边）。实测产线已经把
透明区 RGB 压到 0（白边/黑边都不会出现）。

如果用户回报有黑边，按顺序查：
1. 是不是把 RGB 重新写回透明区了（比如用别的工具导了一次）；
2. 引擎的压缩格式（ETC/ASTC）把 RGB 也压了——换 RGBA8888 或开 alpha 分离；
3. 是这层本来就没有预乘（premultiply）——引擎侧把 Premultiply Alpha 打开。

## 验收清单

跑完 `10` 之后，**必须逐条核实**，不要看一眼「差不多」就交：

- [ ] 出了两张图，都叫 `part_head_*` / `part_body_*`；
- [ ] 用 `read_image` 分别看：head 里没有身体，body 里没有头；
- [ ] 两张叠起来 = 原始角色，**接缝处没有一条透明缝**（这条最容易漏）；
- [ ] 脖子归属明确——点头的时候不会露出空洞；
- [ ] 四角透明区的 RGB 是 0（不是黑）；
- [ ] 手部：默认没拆。用户要拆手时**明说这条链拆不准**（见下）。

## 手部为什么默认不拆

`hand_yolov8s` 在动漫人像上不可靠：手经常和袖口、头发、武器糊在一起，
检出来的框偏、或者干脆漏检。硬拆的结果是手被切成半只，或者把袖口当手。

`ENABLE_HAND` 默认 `False`。用户坚持要拆手时：说清楚现在拆不准，
建议要么手动补、要么换一张手部清晰且离身体远的图、要么接受 head/body 两层先上，
手跟着 body 动。

## 接入 Spine / DragonBones

- 两层按 **body 在下、head 在上** 的顺序建槽位（slot 顺序错会遮挡）。
- 轴心（pivot）：head 的轴心放在**脖子根部**（下巴下方正中），不是图片中心；
  body 的轴心放角色重心。轴心错了转头的支点就不对。
- 两层的贴图尺寸必须一致（640×896），导入时不要各自裁边——裁了就对齐不了。
- 骨骼：head 挂到 `bone_head`，body 挂 `bone_root`；点头/转头只动 `bone_head`。
- 如果引擎按图集打包：两张打进同一张 atlas，且**不要**开 trim（会破坏对齐）。

## 排查

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 角色没了、背景留着 | `JoinImageWithAlpha` 前少了 `InvertMask` | 检查该节点 |
| 头身重叠 | body 没减掉 head | 检查 `body = foreground − head` 那一步 |
| 头身之间有条缝 | expand 太小 | 回到 25，别往下调 |
| 肩膀跟着头转 | expand 太大 | 确认是 25，不是 70 |
| 有黑边 | 透明区 RGB 非 0 或引擎压缩 | 见上文排查顺序 |
| 头只切了半张脸 | SAM 提示框偏了 | 阈值/膨胀改回 0.30 / 12，或换更正的正面图 |
| 全身图拆出来没意义 | prompt 写了 full body | 换 `upper body` / `portrait` 重出 |
