# 光效粒子：用法与接入

## 产线出什么

1024×1024 RGBA **×12 张**（batch=12），黑底能量/粒子贴图。实测：

- 有效像素覆盖率 `nz ≈ 0.237 ~ 0.252`（每张只有 1/4 面积有东西，其余全透明）；
- 完全透明边缘占比 ≈ 0.75。

这两条说明它是**稀疏的、中心亮四周散**的形态——就是要用加色叠在场景上，
不是一张「完整的图」。

## 必须是黑底 + 加色混合

加色混合的数学是 `结果 = 背景 + 贴图`。它有个硬性质：**黑色是加法的单位元**
（`背景 + 黑 = 背景`）。所以：

- 底是黑的 → 黑色区域叠上去完全不影响场景，只有亮的部分「发光」；
- 底是白的 → 白色区域叠上去直接把场景刷爆成白屏。

因此：
- 产线的 prompt 里 `black background` **必须留着**；
- 不要试图把黑底「抠掉」——alpha 已经表达了透明，RGB 留黑才是正确的加色输入；
- 引擎里混合模式选 **Additive / Linear Dodge (Add) / ONE, ONE**，
  **不能选 Alpha Blend**（普通混合会拿黑底去乘，光效变灰变暗）。

## 引擎侧参数

| 引擎 | 怎么做 |
|------|--------|
| Unity (URP) | Shader 用 `Blend One One`；粒子使用 Additive 材质；Texture 关 sRGB 二次转换的情况要按项目色彩空间确认 |
| Unity (内置) | `Particles/Additive` 着色器，或自写 `Blend SrcAlpha One` 做软加色 |
| Godot | `CanvasItemMaterial` 的 `blend_mode = BLEND_MODE_ADD`；`Particles2D`/`GPUParticles2D` 的 material 上设 |
| Cocos Creator | 材质 `blendSrc = ONE, blendDst = ONE`（加色） |

补充：
- **不要开 Mipmap 的各向异性去追求锐利**，光效本来要软；开 Mipmap 反而更顺。
- 想要「边缘完全淡出」时，靠 alpha 的软过渡，别去增加 alpha 对比度。
- 尺寸别按原图 1024 用——实际游戏里一张爆炸通常 128–512。缩放用双线性，别用 point。

## 挑图

一次出 12 张，**不要指望 12 张都能用**。挑的顺序：

1. 形态对（是爆炸/火花/环绕/刀光，不是一坨糊）；
2. 中心有明确的亮核（加色叠上去要有「亮点」）；
3. 边缘散得开（不然叠上去是一块硬圆）；
4. 没有奇怪的具象物（人脸、文字、随机符号——SDXL 偶尔会画出来）。

留 3–4 张做一套就够了。剩下的不用删，放在同一个目录里当备选。

## 验收清单

- [ ] 12 张都是 1024×1024；
- [ ] `read_image` 看是**黑底**（不是白底、不是灰底）；
- [ ] 有 alpha 通道（RGBA，不是 RGB）；
- [ ] 引擎里叠在场景上试一次：背景没被刷白、光效发光；
- [ ] 缩放后边缘仍软（没有硬边框）。

## 排查

| 现象 | 原因 | 怎么办 |
|------|------|--------|
| 叠上去一个黑方块 | 用了 Alpha Blend，不是加色 | 改混合模式为 Additive / ONE ONE |
| 光效发灰、不亮 | 同上，或底是白的 | 混合模式 + 重出时带 `black background` |
| 整屏刷白 | 底是白的，或 alpha 没生效 | 检查是 RGBA；检查 prompt 里 `black background` |
| 边缘有硬方框 | 贴图边界处 RGB 非纯黑 / alpha 突变 | 换一张；或在材质里开 clamp + 让 UV 留边 |
| 12 张全糊 | prompt 太抽象 | 加具体形态词：`explosion, sparks, ring, slash` |
| 出现人脸/文字 | SDXL 跑偏 | 弃掉这张；负向词补 `text, character, face` |

## 什么时候别用 11

- 用户要的是**序列帧动画**（爆炸 8 帧播一遍）——11 出的是单张静帧，要自己做序列或程序化动画；
- 用户要的是 **muzzle flash 那种极短帧**——单张够用，但要在引擎里配合闪烁曲线；
- 用户要**写实火焰/烟雾**——这套是日式萌系的风格化光效，写实的建议直接找素材库。
